# 한글원샷 — 프랑스 한글학교 레벨별 자료 저장소

QR 한 번(원샷)에 내 레벨 자료가 열리는 **한 장짜리 페이지**. 교사들이 주제 → 상/중/하로 나눠 둔 자료를 페이지에서 로그인해 올리면 타일·띠·버튼으로 보여 준다. 구글시트는 뒤에서 자료를 담아 두는 곳일 뿐, 교사·학습자 누구도 시트를 보지 않는다. 학습자 쪽은 아무것도 저장하지 않는다.
홈 화면에 추가하면 주소창 없이 앱처럼 열린다(웹 앱 설정 `manifest.json` · `sw.js` · `icons/`).

## 파일
| 파일 | 무엇 |
|---|---|
| `index.html` | 페이지 전부(화면·글·동작, 한국어/프랑스어). 휴대폰 앱 모양(아래 탭: 홈·QR 코드·선생님), 화면 폭 900px 이상(PC·큰 태블릿)이면 왼쪽 메뉴와 두 칸 배치로 넓게 보인다. 외부 파일은 QR 그리기(cdnjs qrcodejs)와 글꼴(jsdelivr Pretendard) 둘 |
| `config.js` | 설정: 앱스 스크립트 주소(`API_URL`), 제목, 레벨 설명, 자료 유형, 소속 학교 16곳(`SCHOOLS`) |
| `sample-data.js` | 견본 자료·견본 교사 코드. `API_URL`이 비어 있을 때(시험 모드)만 쓰인다 |
| `apps-script/Code.gs` | 구글시트에 붙이는 서버 코드(읽기·교사 로그인·올리기·숨기기) |
| `manifest.json` · `sw.js` · `icons/` | 홈 화면에 추가(앱 이름·아이콘·전체 화면). `sw.js`는 늘 인터넷에서 먼저 받고 끊겼을 때만 저장해 둔 화면을 쓴다 |
| `serve.py` | 로컬 확인용 서버(`python serve.py 8765` → http://127.0.0.1:8765/, 뒤에 `mock`을 붙이면 `API_URL`을 비워 시험 모드로 연다) |

## 로컬에서 보기
이 폴더에서 `python serve.py 8765`(맥·리눅스는 `python3`) 뒤 브라우저에서 http://127.0.0.1:8765/ (QR 그리기만 인터넷이 필요).
공개 주소: https://humanteacher89-cell.github.io/hangeul-oneshot/ (이 저장소가 그대로 공개된다. 저장소 이름 = 주소라 바꾸지 않는다).
시험 모드 교사 코드: 1234(김선생·파리), 5678(이선생·보르도), 가입 코드: HANGEUL. 올린 자료·가입한 교사는 그 브라우저의 localStorage에만 남는다.

## 실제 시트와 연결하기 (휴먼쌤, 한 번)
1. 구글시트 새로 만들기 → 확장 프로그램 → Apps Script → `apps-script/Code.gs` 내용 붙여 넣기 → 저장.
2. 함수 `setup` 실행(권한 허용) → 탭 자료·주제·교사·설정이 생기고, 내 드라이브에 '한글원샷 자료' 폴더가 생긴다(교사가 올린 파일이 모이는 곳). 드라이브 권한도 이때 허용한다.
3. 배포 → 새 배포 → 웹 앱 → 실행 사용자 '나', 액세스 '모든 사용자' → 주소(…/exec) 복사.
4. `config.js`의 `API_URL`에 그 주소를 넣는다. 끝. **시트는 아무와도 공유하지 않는다**(스크립트가 휴먼쌤 이름으로 읽고 쓴다).
5. 교사는 페이지 선생님 탭 → '가입하기'에서 직접 가입한다(2026-10-24). `setup`이 '설정' 탭에 `join_code`(가입 코드 6자리)를 한 번 만든다 → 협의회가 교사들에게 알려 준다. 가입 코드를 아는 사람만 이름·학교를 넣고 가입하고, 시트 서버가 로그인 코드 8자리를 만들어 '교사' 탭에 적고 화면에 보여 준다(이름은 겹치지 않게 받는다). 가입 코드가 새면 값을 바꾸고, 가입을 닫으려면 값을 비운다. 휴먼쌤이 '교사' 탭에 이름·코드를 직접 적어도 된다(학교 칸은 처음 골라져 있을 학교).
6. 이미 배포했다면: 새 `Code.gs`를 붙여 넣고 저장 → `setup` 한 번 더(가입 코드·'가입일' 머리글이 생김) → 견본이 남아 있으면 `cleanSamples` 한 번 → '배포 관리'에서 새 버전으로 배포(주소는 그대로).

## 시트 '자료' 탭 열
id · 묶음 · 주제 · 레벨(상/중/하) · 제목 · 유형 · 링크 · 설명 · 시간 · 학교 · 올린이 · 올린날짜 · 공개(N이면 숨김)
페이지에서 올리면 id·올린이·올린날짜는 자동, 학교는 교사가 올리기 화면에서 고른 이름(`config.js` SCHOOLS의 한국어 이름). 휴먼쌤이 시트에서 직접 고칠 때는 id를 비워도 된다(화면에서는 줄 번호로 구분).
'주제' 탭(선택): 주제 · 프랑스어 · 묶음 · 순서 · 아이콘(이모지 하나, 비우면 주제 이름으로 자동). '설정' 탭: title · subtitle · notice(첫 화면 안내 한 줄) · join_code(가입 코드, 공개 자료에는 실리지 않음).
'교사' 탭: 이름 · 학교 · 코드 · 활성(N이면 막음) · 가입일(가입 화면으로 들어온 줄만).

## 자료 형식 (2026-10-07, 파일 올리기 2026-10-18)
- **올리기 화면(2026-10-24 휴먼쌤).** 자료 칸은 왼쪽 '링크'(처음 골라짐, 안내 "웹앱/유튜브 등 링크를 붙여넣어주세요") · 오른쪽 '파일(PDF/이미지)'. 유형은 게임·학습지·영상·퀴즈·기타 다섯. 걸리는 시간 칸은 없고 한 줄 설명은 선택. 주제·묶음 칸은 앱 모양 고르기 목록(적으면 걸러지고, 없으면 '새 주제로 쓰기').
- **파일 올리기.** 교사가 올리기 화면에서 파일(PDF·사진만, 10MB까지 — 2026-10-24 휴먼쌤 "간단하게 파일은 pdf랑 사진 업로드, 영상은 링크")을 고르면 시트 서버가 휴먼쌤 드라이브 '한글원샷 자료' 폴더에 저장하고, '링크가 있는 모든 사용자 보기'로 연 뒤 그 링크를 시트 링크 칸에 적는다. 파일 주인이 휴먼쌤이라 교사가 자기 드라이브에서 지워도 남는다. 숨기기를 해도 파일은 지우지 않는다(보관). 영상은 크기 때문에 유튜브 '일부 공개' 링크로 받는다. HTML 파일은 드라이브에서 웹페이지로 열리지 않아 받지 않는다(사이트는 공개 주소를 링크로).
- **링크 붙여넣기.** 유튜브·공개 사이트·구글 문서/슬라이드/설문처럼 원래 링크인 자료는 지금처럼 링크 하나로 받는다. 학습자에게는 파일이든 링크든 같은 카드(제목·유형·시간·학교)로 보인다.
- **대량 올리기(휴먼쌤용, 2026-10-24).** 휴먼쌤 드라이브 '한글원샷 올리기\<주제>\<하·중·상>\'에 PDF·사진을 넣고, 영상 링크는 시트 '올리기' 탭(주제·레벨·제목·링크, 유형·설명은 골라서)에 한 줄씩 적은 뒤 Apps Script 편집기에서 `importAll`을 실행하면 모두 '자료' 탭에 올라간다. 올린 파일은 '한글원샷 자료' 폴더로 옮기고 올린 줄은 지워서 다시 실행해도 겹치지 않는다. 틀린 줄은 '확인' 칸에 까닭이 남는다. 처음 실행하면 폴더(주제별 하·중·상)와 탭이 생긴다. 앱 화면은 그대로. '한글원샷 올리기' 바로 아래 .txt 파일(한 줄 = `주제 | 레벨 | 제목 | 링크`, 유형·설명은 뒤에 `|`로)도 읽는다 — 휴먼쌤이 대화창에 준 링크를 창이 이 파일로 적어 넣는 길. 다 올리면 휴지통, 틀린 줄은 남고 끝에 '← 까닭'.
- 올리기 화면이 링크를 알아보고 한 줄로 알려 준다: 드라이브 파일·문서(공유 설정 안내), 드라이브 폴더(파일 하나 링크 권함), 사본 만들기 링크(구글 계정 필요), http 주소(https 권함). 내 컴퓨터 주소(localhost 등)나 https로 시작하지 않는 글은 올라가지 않는다.
- 직접 만든 사이트는 공개 주소(https://…)가 있어야 한다.

## 지킬 것
- 링크로 넣은 드라이브 파일·문서는 교사가 직접 '링크가 있는 모든 사용자 보기'로 공유해야 학습자가 연다(파일 올리기는 스크립트가 알아서 연다).
- QR은 종이 한 장에 하나씩(여러 개가 가까이 있으면 카메라가 헷갈린다). 인쇄 화면이 한 장에 한 개씩 뽑는다.
- 교사 로그인은 '코드' 하나로 하는 간단한 방식이다(비밀번호 수준의 보안은 아님). 코드가 새면 시트에서 그 교사 코드를 바꾸면 된다. 틀린 코드·가입 코드가 10분에 30번 넘게 오면 시트 서버가 10분 동안 로그인·가입을 막는다(기기를 가릴 수 없어 모두 함께 막힘).
- 주소(해시) 모양: `#/t/주제` 주제 화면, `#/t/주제/하` 레벨 바로 열기(레벨 QR), `#/qr` 첫 화면 QR과 주제 목록, `#/qr/주제` 주제·레벨 QR 인쇄(아래 자료별 QR 목록), `#/mq/자료id` 자료 하나의 QR(찍으면 자료 링크가 바로 열림, 자료 카드의 QR 버튼), `#/login` `#/join` `#/mine` 선생님 탭(로그인·가입·내 자료), `#/upload/주제/레벨` 자료 올리기(주제·레벨 미리 채움).
- 주소로 처음 들어오면(QR) 주제 화면 위에 'QR로 바로 왔어요'가 잠깐 보인다. 학습자 쪽은 언어·레벨 어느 것도 저장하지 않는다.
- 홈 화면 추가 안내는 첫 화면에만, 휴대폰에서만 보인다(안드로이드 크롬은 '추가' 단추, 아이폰은 공유 버튼 안내). 이미 앱으로 열었으면 보이지 않는다. 실제로 설치되려면 공개 주소(https)여야 한다.
- 학교를 더하거나 빼려면 `config.js` SCHOOLS만 고친다(16곳. 2026-10-24 리옹 에콜리움을 빼서 XR개발부 '프랑스 한글학교 로비' 17곳과는 다르다).
